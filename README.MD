# 🎮 GameDev 2D - Paraiso Animation

Isang **2D Platformer Game** na binuo gamit ang **Unity 6** at **C#**. Ang larong ito ay nagtatampok ng mga basic platforming mechanics, physics, at animations.

## 🚀 Mga Tampok sa Laro (Features)
* **Player Movement:** Smooth na pagtakbo at pagtalon ng character gamit ang C# script (`BoxControl.cs`).
* **Interactive Elements:** May mga tiles, trampoline traps (`TrampolineTrap.cs`), at kulay na nababago.
* **Physics & Collisions:** Paggamit ng Unity 2D Physics para sa tamang paglapag sa sahig.

## 🛠️ Mga Ginamit na Teknolohiya (Tech Stack)
* **Game Engine:** Unity 6 (Version 6000.5)
* **Programming Language:** C# (Visual Studio / VS Code)
* **Version Control:** Git & GitHub Desktop

## 🕹️ Paano Laruin (Controls)
* **A / D** o **Left / Right Arrow Key** - Para lumakad pakaliwa at pakanan.
* **Spacebar** - Para tumalon.

## 📂 Paano Patakbuhin ang Project
1. I-download o i-clone ang repository na ito.
2. Buksan ang **Unity Hub** at i-click ang *Add project mula sa disk*.
3. Piliin ang folder na ito at buksan gamit ang Unity 6.
